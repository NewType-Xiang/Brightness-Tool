# Brightness-Tool
A lightweight game brightness tool built using Codex, designed primarily to address the poor lighting and shadow issues in *Hunt: Showdown*. You might ask, "Why not just use GamePP instead?" Well, this tool is much lighter, completely ad-free, and far less frustrating to deal with.
